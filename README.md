# 📖 项目介绍

**滴滴拉屎（Didi Shit）** 是一个公共厕所发现与评分平台。

项目希望解决一个简单但真实的问题：

> "当你急需厕所的时候，如何快速找到一个合适的地方？"
> 🙅‍♀️推门“惊喜”
> 🙅‍♀️年久失修
> 🙅‍♀️恶臭气味

通过结合地图服务与用户反馈，帮助你：

- 快速寻找附近公共厕所
- 查看厕所信息
- 分享使用体验
- 评价厕所环境

让公共厕所信息更加清香、透明。


---

# ✨ 功能特点

## 🗺️ 公共厕所地图

- 基于高德地图 Web JS API
- 在地图中展示厕所位置
- 支持地图浏览
- 支持地点查看


## 🔍 厕所搜索

支持：

- 根据厕所名称搜索
- 快速定位目标厕所
- 提高寻找效率


## 🚽 用户共建

用户可以：

- 在地图中添加厕所
- 分享新的厕所位置
- 完善公共厕所信息


## ⭐ 厕所评分

支持：

- 厕所质量评分
- 查看评分数据
- 根据评价选择厕所


## 💬 评论与图片分享

用户可以：

- 发布厕所评价
- 分享使用感受
- 上传图片展示环境


## 📊 数据统计

提供：

- 厕所数量统计
- 用户评分统计
- 社区贡献数据
